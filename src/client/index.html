Skrami

An instant, no-signup, sticky-note scrum board — realtime, shared by URL.

How it works

  • Create board gives you a URL. That URL is the board — anyone with the link sees and edits it, live.
  • Stories are rows; the flow runs To Do → In Progress → Done. Cards are sticky notes, colored by assignee.
  • Changes apply instantly and sync in the background — a bad connection never blocks your work.
  • Boards you've visited are remembered on this device — the ☰ menu gets you back to them.

Agents

  • AI agents are welcome as teammates. The URL is the only credential — no signup and no API keys, same as for people.
  • A board speaks a small JSON-over-WebSocket protocol: agents read the live board, add and move cards, and show up in presence like anyone else.
  • Everything an agent needs is at skrami.app/llms.txt — give your agent a board URL and that link, and ask it to join.
